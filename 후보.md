## connector (mcp) - 보류

- perplexity
- firecrawl
- playwright
- composio

### install

API key 는 셸 env 로 먼저 export. README 에 값 직접 적지 말 것.

```bash
export PERPLEXITY_API_KEY=...
export FIRECRAWL_API_KEY=...
export COMPOSIO_API_KEY=...
```

`--scope user` = global, `--scope project` = `.mcp.json` 생성(커밋 가능). 생략 시 `local`(현재 프로젝트, 나만).

```bash
# perplexity - 공식 @perplexity-ai/mcp-server
claude mcp add perplexity --scope user \
  -e PERPLEXITY_API_KEY=$PERPLEXITY_API_KEY \
  -- npx -y @perplexity-ai/mcp-server

# firecrawl - 공식 firecrawl-mcp
claude mcp add firecrawl --scope user \
  -e FIRECRAWL_API_KEY=$FIRECRAWL_API_KEY \
  -- npx -y firecrawl-mcp

# playwright - microsoft/playwright-mcp, key 불필요
claude mcp add playwright --scope user \
  -- npx -y @playwright/mcp@latest

# composio (Rube) - remote http, OAuth 로그인 방식
claude mcp add composio --scope user --transport http https://rube.app/mcp
claude mcp login composio
```

composio 를 API key 로 붙이려면 대신:

```bash
claude mcp add composio --scope user --transport http https://rube.app/mcp \
  -H "X-API-Key: $COMPOSIO_API_KEY"
```

### verify

```bash
claude mcp list
claude mcp get perplexity
```
